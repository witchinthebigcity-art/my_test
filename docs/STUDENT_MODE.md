# Персональный режим ученика

## Безопасность и данные

- Кабинет создаёт только администратор через `/admin`.
- Первый вход разрешён только с заранее указанного Telegram username.
- После входа кабинет привязывается к подписанному Telegram ID; последующая смена username не отбирает доступ.
- Пароли хранятся как PBKDF2-HMAC-SHA256 с отдельной случайной солью, а временный пароль показывается администратору один раз.
- Конспекты, ДЗ и ответы лежат вне статической папки и выдаются только через API после повторной проверки Telegram-подписи и владельца файла.
- Не вносите в поле «важные факты» медицинские данные, адреса, документы и другую информацию, которая не нужна для обучения.
- В ручном режиме данные не передаются OpenAI: преподаватель присылает тест и ДЗ текстом или PDF.
- В автоматическом режиме текст конспекта, учебная цель и указанные учебные особенности передаются модели OpenAI для генерации теста и ДЗ. Учеников и родителей следует уведомить об этой обработке.

## Настройка сервера

Нужны существующие переменные `TOKEN`, `WEBAPP_URL`, `ADMIN_ID`, `OPENAI_API_KEY`. Модель задаётся через `OPENAI_GRADER_MODEL`.

Railway Volume должен быть подключён к `/data`. Там сохраняются:

- `student_learning.json` — записи учеников, уроков и результатов;
- `student_learning/` — приватные PDF и прикреплённые работы.

Без постоянного Volume данные пропадут при новом развёртывании.

## Сценарий администратора

1. `/admin` → «Добавить ученика» → отправить семь строк по подсказке.
2. Передать показанный временный пароль ученику лично.
3. `/admin` → «Добавить конспект урока» → выбрать ученика.
4. Выбрать «Заполнить тест и ДЗ вручную» или автоматическую генерацию. Ручной режим работает без OpenAI API.
5. В ручном режиме прикрепить PDF-конспект. Затем бот отдельно запросит тест, а после него — ДЗ. Обе части можно прислать текстом или PDF.
6. `/admin` → «Проверить ДЗ» → выбрать ученика. Бот отправит последние работы в закрытый чат администратора.

После сохранения урока бот ежедневно напоминает ученику о ДЗ в заданное время. Напоминания прекращаются после отправки учеником файлов по этому уроку.

Тестовый PDF должен содержать выделяемый текст. Для каждого вопроса нужны строки `1. Вопрос`, `А) ...`, `Б) ...`, `В) ...`, `Г) ...`, `Ответ: Б` и `Пояснение: ...`. Ученик видит вопросы по одному; пояснение показывается сразу после неверного ответа.

## Ограничения загрузки

Один файл ученика — до 15 МБ. Разрешены PDF, JPG, PNG и WebP. За один запрос принимается до 50 файлов; следующие файлы можно отправить отдельной партией. Это защищает сервер от исчерпания памяти, не ограничивая общее число материалов.
