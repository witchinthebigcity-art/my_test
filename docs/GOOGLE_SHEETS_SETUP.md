# Как добавлять задания через Google Таблицу

Бот использует одну таблицу для 8, 9, 10 и 11 классов. Каждая строка — одно задание. После изменения опубликованной таблицы новое задание появится в боте не позднее чем через 60 секунд.

## 1. Подготовьте столбцы

В первой строке таблицы укажите названия:

1. `Класс`
2. `Тема`
3. `Вопрос`
4. `Вариант 1`
5. `Вариант 2`
6. `Вариант 3`
7. `Вариант 4`
8. `Правильный ответ`
9. `Решение`
10. `Изображение`
11. `Изображение решения`
12. `Активно`

Правила заполнения:

- В `Класс` укажите только `8`, `9`, `10` или `11`.
- В `Правильный ответ` укажите номер от `1` до `4`, а не текст ответа.
- В `Активно` напишите `да`, чтобы показывать задание, или `нет`, чтобы временно скрыть его.
- Столбцы с изображениями необязательны.
- Формулы можно писать как `$x^2+3x$` или `$$x=\frac{-b\pm\sqrt{D}}{2a}$$`.

Готовый пример находится в `docs/google-sheets-template.csv`. Его можно импортировать в Google Таблицы.

## 2. Как проще всего добавить картинку

1. Откройте Google Drive.
2. Загрузите туда файл JPG, PNG или WebP.
3. Нажмите на файл правой кнопкой → `Открыть доступ`.
4. В разделе общего доступа выберите `Все, у кого есть ссылка` → `Читатель`.
5. Нажмите `Копировать ссылку`.
6. Вставьте ссылку в столбец `Изображение` нужного задания.
7. Если отдельная картинка должна показываться только после ответа, вставьте её в `Изображение решения`.

Не используйте меню Google Таблиц `Вставка → Изображение в ячейку`: при публикации в CSV такая картинка не передаётся боту. Нужна именно ссылка в текстовой ячейке.

Подойдут также прямые публичные ссылки на изображения с другого сайта, начинающиеся с `https://`.

## 3. Опубликуйте таблицу

1. В Google Таблице откройте `Файл` → `Поделиться` → `Опубликовать в интернете`.
2. Выберите лист с заданиями.
3. Выберите формат `CSV`.
4. Нажмите `Опубликовать`.
5. Скопируйте полученную ссылку.

Важно: опубликованная база заданий доступна по ссылке. Не храните в ней персональные данные учеников.

## 4. Подключите ссылку к Railway

1. Откройте проект Railway.
2. Выберите сервис `my_test`.
3. Откройте вкладку `Variables`.
4. Создайте переменную `QUESTIONS_CSV_URL`.
5. Вставьте в неё CSV-ссылку из предыдущего шага.
6. Сохраните переменную и дождитесь успешного деплоя.

Переменная `QUESTIONS_CACHE_TTL` управляет задержкой обновления в секундах. По умолчанию установлено `60`. Уменьшать её обычно не требуется.

## 5. Как добавлять новые задания дальше

Добавьте новую строку, заполните обязательные ячейки и укажите `да` в столбце `Активно`. Повторно публиковать таблицу или перезапускать Railway не требуется.

## 6. Массовая загрузка изображений из папок классов

Чтобы не вставлять сотни ссылок вручную, бот уже настроен на публичную корневую
папку `1CIagfcGHZO_Sdk2G1QysBNg-rX06c_-r`. Внутри неё он сам находит папки
8–11 классов. Дополнительная настройка Railway не требуется, пока для корневой
папки и её содержимого включён доступ «Все, у кого есть ссылка».

После этого изображения достаточно загружать в папку нужного класса и называть так:

```text
6 - 120.png
7 - 2,5.jpg
8 - -3.webp
```

До тире указывается уникальный номер задания внутри класса, после тире — правильный
ответ. Расширение в имени необязательно. Поддерживаются JPG, PNG и WebP. Старые
файлы `1`–`5` остаются в проверенной базе и повторно не добавляются. Если новый
файл №6 и выше назван без ответа или один номер повторяется, бот не заменит
рабочую базу и сообщит, какой файл нужно исправить.

Для ручного обновления:

1. Откройте чат с ботом с администраторского аккаунта.
2. Отправьте `/admin`.
3. Нажмите `🔄 Обновить базу заданий`.
4. Дождитесь отчёта с количеством текстовых заданий и картинок для каждого класса.

Команда `/refresh` запускает тот же механизм без открытия панели.

### Резервный вариант через Google Apps Script

Если Google изменит формат публичных папок, используйте стабильный индекс из файла
`docs/google-drive-question-index.gs`: разверните его как Web app с доступом `Anyone`
и запишите адрес `/exec` в переменную Railway `DRIVE_INDEX_URL`. При наличии этой
переменной бот автоматически предпочитает Apps Script прямому чтению папки.
