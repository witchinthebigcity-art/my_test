# Публикация без возврата к старой версии

Основной исходник приложения — ветка `main` репозитория
`witchinthebigcity-art/my_test`. Изменения, загруженные только командой
`railway up`, не обновляют GitHub. Следующая сборка из GitHub, в том числе
после изменения переменных Railway, может вернуть старый код.

## Перед публикацией

1. Выполнить `python3 -m unittest discover -s tests -q`.
2. Проверить `git status` и `git diff --cached`. В коммит включать только
   исходники, ресурсы приложения, тесты и документацию.
3. Сохранить изменения коммитом и выполнить `git push origin main`.
4. Проверить в Railway успешное развёртывание этой версии. Если автосборка
   отключена, запустить её из актуальной ветки `main` вручную.
5. Проверить сайт и открытие Mini App из Telegram.

## Настройки и данные

- Токен бота хранится только в переменной Railway `TOKEN`.
- После замены токена не нужно возвращать старый токен или старую версию кода.
- Данные работающего приложения находятся на постоянном томе `/data`.
  Не удалять и не заменять его при публикации исходников.
- `community.json`, списки пользователей, результаты, фотографии и решения
  не должны попадать ни в GitHub, ни в локальную загрузку Railway.
- `.gitignore` и `.railwayignore` исключают эти файлы. Уже отслеживаемые
  Git файлы такие правила не скрывают — перед коммитом нужна проверка.

## Автопроверка второй части

Проверка решения моделью требует отдельно настроенного `OPENAI_API_KEY`.
Модель задаётся `OPENAI_GRADER_MODEL` (по умолчанию `gpt-5-mini`).
`MATHPIX_APP_ID` и `MATHPIX_APP_KEY` включают отдельное распознавание фото
в редактируемый текст. Без этих ключей сервисы не включены.

Текущий резервный режим `structured-check` сравнивает строки ответов и
проверяет только длину пояснения. Он не читает фотографию и не является
экспертной проверкой по критериям ЕГЭ/ОГЭ. Его балл нельзя использовать
для оценки качества рукописного решения. При ошибке запроса к модели
текущая реализация также переключается на этот режим.
