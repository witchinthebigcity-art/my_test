# Игра «Ты — эксперт»

## Структура Google Drive

Корневая папка должна быть открыта на просмотр по ссылке и содержать ровно две
папки:

- `Решения` — фотографии работ учеников;
- `Ответы` — фотографии экспертных разборов.

Работу называют по схеме `номер - балл`, например `1 - 1.jpg`. Соответствующий
разбор называют только номером: `1.jpg`. Расширение файла Google Drive может
скрывать — обе записи всё равно распознаются.

Для каждой работы обязателен один разбор с тем же номером. Повторяющиеся номера,
отсутствующий разбор и балл выше максимального отклоняют обновление банка, чтобы
ученику не попалась неоднозначная пара.

## Настройки

- `EXPERT_GAME_FOLDER_ID` — ID корневой папки. По умолчанию используется
  тестовая папка `10zrD0b4U64JFALp6lUqjzaZl9Gn1DYzN`.
- `EXPERT_GAME_MAX_SCORE` — максимальная оценка, по умолчанию `2`.
- `EXPERT_GAME_ENABLED` — временный флаг запуска. Пока он не установлен в
  `true`, карточка остаётся заблокированной, а сервер не позволяет начать игру.

Стартовый API-ответ содержит только фотографию работы и кнопки `0…максимум`.
Экспертный балл и ссылка на разбор не передаются в браузер до ответа. При точном
совпадении показывается подтверждение; при ошибке дополнительно открывается
соответствующая фотография из папки `Ответы`.

Повторения исключаются внутри одного ключа прохождения. После того как ученик
оценит все доступные работы, начинается новый цикл.
